03 / THE EVIDENCE

Know what
the sky can say.

Geometric visibility is not a guarantee.

A body’s center above a local tangent plane is not proof of unobstructed terrain line of sight, available electric power, or working radio communication. True terrain-aware investigation must use validated elevation models and a complete sightline.

Every answer needs a source.

The finished product should link precise ephemeris requests, site definitions, time sampling, and scientific limitations to each displayed reading. This interface preview contains no downloaded astronomical observations.
